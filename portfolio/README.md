# Personal Portfolio Website

This is my personal portfolio project. It is a simple website built to showcase my work, skills, experience, and contact information in a clean and professional way.

## What this project is for

This portfolio helps visitors:

- Learn more about me
- View my projects and skills
- Understand my experience and background
- Contact me easily

It is designed to look modern, be easy to read, and work well on both desktop and mobile devices.

## Features

- Responsive design for mobile and desktop
- About section for personal introduction
- Skills section for technologies and strengths
- Projects section to display your work
- Experience section for background and career history
- Contact section for messages or job opportunities
- Easy to customize with your own content

## Tech Stack

- HTML
- CSS
- JavaScript

## How to run this project

### 1. Open the project folder

```bash
cd portfolio
```

### 2. Start the website

You can do one of the following:

- Open `index.html` directly in your browser, or
- Use a local development server such as Live Server in VS Code

### 3. View the site

Once opened in the browser, the portfolio will load and you can see the design and content.
